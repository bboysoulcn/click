Quick Start

1. Add the script to your page:

<script defer src="http://localhost:8000/static/click.js"></script>

2. Add a button:

<button class="click-button" aria-hidden="true"></button>

3. Style it (optional):

<link rel="stylesheet" href="http://localhost:8000/static/click.css">

That's it! The button will automatically display with a heart icon and show the current count.

Customization

Use different icons:

<!-- Built-in icons: heart, thumbs_up, upvote -->
<button class="click-button" data-icon="thumbs_up" aria-hidden="true"></button>

<!-- Any emoji -->
<button class="click-button" data-icon="💯" aria-hidden="true"></button>

Custom slug for multiple buttons:

<button class="click-button" data-slug="/custom-page" aria-hidden="true"></button>
